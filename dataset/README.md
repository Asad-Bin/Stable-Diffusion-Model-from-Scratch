# Dataset Module

Dataset loading, preprocessing, caching, and text encoding utilities for the diffusion model.

## Files

| File | Description |
|------|-------------|
| `load_dataset.py` | Main dataset classes and data loading pipeline |
| `clip.py` | CLIP tokenizer and text model initialization |

## Core Classes

### `ButterflyDatasetWithPrompts`

PyTorch Dataset wrapper that pairs images with Qwen2-VL generated captions.

```python
from dataset.load_dataset import ButterflyDatasetWithPrompts

dataset = ButterflyDatasetWithPrompts(
    hf_dataset,
    transform=transforms,
    save_prompts_file="prompts.json",
    regenerate_prompts=False  # Use cached prompts
)
```

### `CachedLatentDataset`

Efficient dataset that loads pre-computed VAE latents and CLIP embeddings from disk.

```python
from dataset.load_dataset import CachedLatentDataset

cached_dataset = CachedLatentDataset(latent_dir="cached_latents/")
```

## Main Functions

### `LoadData()`

Primary entry point for loading training data:

```python
from dataset.load_dataset import LoadData

dataloader = LoadData(
    prompt_style="queenvl",      # Use Qwen2-VL captions
    regenerate_prompts=False     # Load from cache
)
```

### `cache_latents_to_disk()`

Pre-computes and caches VAE latents and CLIP embeddings:

```python
from dataset.load_dataset import cache_latents_to_disk

cache_latents_to_disk(dataset, save_dir="cached_latents/")
```

### `encode_text_with_clip()`

Encodes text prompts using CLIP text encoder:

```python
from dataset.load_dataset import encode_text_with_clip

embedding = encode_text_with_clip("a beautiful butterfly")
```

## Caching System

### Prompt Cache
- **Location**: `dataset/huggingface_butterflies/prompts/`
- **Format**: JSON files mapping image IDs to captions
- **Generated by**: Qwen2-VL vision-language model

### Latent Cache
- **Location**: `dataset/huggingface_butterflies/latents/`
- **Contents**: `.pt` files with VAE latents and CLIP embeddings
- **Benefits**: Eliminates VAE encoding overhead during training

## Data Pipeline

```
Raw Image (512×512×3)
        ↓
    Transform (normalize to [-1, 1])
        ↓
    VAE Encode → Latent (4×64×64)
        ↓
    Cache to Disk (.pt files)

Text Prompt
        ↓
    CLIP Tokenizer → Token IDs
        ↓
    CLIP Text Model → Embedding (768-dim)
        ↓
    Cache alongside latent
```

## Qwen2-VL Integration

The module integrates Qwen2-VL for automatic caption generation:

```python
from dataset.load_dataset import generate_prompt_with_queenvl

caption = generate_prompt_with_queenvl(pil_image)

```
